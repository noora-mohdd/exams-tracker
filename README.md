# 📘 Exam Tracker

A simple web-based Exam Tracker built to help users manage and keep track of exams efficiently. 
The application allows users to add, view, and edit exam-related information through a clean and responsive interface.


## What It Does

- Add and manage exam details  
- View upcoming exams in one place  
- Clean and responsive UI using Bootstrap  


## Built With

- Flask  
- SQLAlchemy  
- Bootstrap CSS  
- Python  


## Running It Locally

To run the project on your system:

```bash
pip install -r requirements.txt
flask run
```

## Deployment (or the Lack of It)

This app was meant to be deployed using Render, but the deployment setup didn’t work out so for now it works perfectly on localhost lol
